## 1. 这套文件的用途与状态

这是一套供团队讨论、学习和实施前参考的总体规划，不是已经实现的产品说明，也不是最终提交的 README 或反思。当前仅完成规划文件；应用代码、CI、单元测试、扫码验证及演示证据均待开发和验收。

作业硬性要求来自 [CS2PP_CW2.pdf](../作业原始材料/CS2PP_CW2.pdf)。以 PDF 印刷页码标识出处。Blackboard 后续公告、Submission Notes 和实际分配的演示时段仍需团队核查；本规划没有查询线上公告。截图是辅助资料，不替代正式 PDF。

标记约定：**【硬性要求】**为原作业规定；**【建议方案】**为本规划的工程选择；**【待确认】**为尚无真实姓名、学号、课堂工具依据或组内决议的事项。

## 3. 本版方案的主要决策

1. 单机运行的 Python 应用，CLI 与 GUI/Web 共用一个 QR 生成服务。不引入云部署、账号系统或数据库服务器。
2. 先共同完成 Version 1 / Level L / Mask 0，再开发个人扩展，不以扩展代替基础阶段。
3. 四个不同的个人扩展：A 负责版本与纠错等级；B 负责完整掩码评分；C 负责分步骤可视化；D 负责使用日志与分析。
4. 外观定制、图像解码不列入本组首版范围。它们是其他可选扩展，不是本组遗漏的共同必做项。
5. Python 3.13.9；使用 numpy、reedsolo、matplotlib；日志扩展使用 pandas。GUI/Web 框架、lint 工具、GitLab Runner 环境需先核查课程允许范围。
6. 所有图均表达拟议方案，不表示已存在的类、函数或部署。Mermaid 图块可在支持 Mermaid 的阅读器中查看，`图示/` 保留对应源文件；关键总览另附 SVG，普通浏览器可查看。

## 5. 首次组会需要完成的事项

- 将 A/B/C/D 映射到真实姓名、8 位学号、个人分支；当前代号不代表已经确认的人选。
- 确认四项扩展的归属。若成员已有选择，更新分工、架构、流程和验收清单后再实施。
- 核查允许的 GUI/Web 框架、lint 工具，以及 GitLab CI Runner 的 Python 3.13.9 可用性。
- 核查官方时间的时区与实际演示时段；文档按原文记录学校时间，不直接当作北京时间。
- 确认自动版本/纠错选择的原文含义，见架构文档中的决策说明。
- 在学校私有 GitLab 仓库创建个人分支并冻结首版公共接口。

## 6. 与最终评分文档的边界

本目录不替代根目录的 `README.md`、`group_reflection.md` 和四份 `individual_<student_id>.md`。上述最终文件目前均待团队根据真实实现和真实经历撰写。

正式 PDF 第 12 页允许 AI 支持初步理解、头脑风暴和结构规划，但禁止直接复制其输出作为提交成果，也禁止借助 AI 润色已有作品或迭代共创最终成果。本目录应作为前期规划参考，团队自行实现和撰写评分材料，并如实记录学习辅助工具的使用。
