## 3. 本版方案的主要决策

1. 单机运行的 Python 应用，CLI 与 GUI/Web 共用一个 QR 生成服务。不引入云部署、账号系统或数据库服务器。
2. 先共同完成 Version 1 / Level L / Mask 0，再开发个人扩展，不以扩展代替基础阶段。
3. 四个不同的个人扩展：A 负责版本与纠错等级；B 负责完整掩码评分；C 负责分步骤可视化；D 负责使用日志与分析。
4. 外观定制、图像解码不列入本组首版范围。它们是其他可选扩展，不是本组遗漏的共同必做项。
5. Python 3.13.9；使用 numpy、reedsolo、matplotlib；日志扩展使用 pandas。用户已确认课堂使用PyQt5，界面选用PyQt5本地桌面GUI；具体版本与机房兼容性仍需验证。lint工具和GitLab Runner环境仍需核查。
6. 所有图均表达拟议方案，不表示已存在的类、函数或部署。Mermaid 图块可在支持 Mermaid 的阅读器中查看，`图示/` 保留对应源文件；关键总览另附 SVG，普通浏览器可查看。
7. 用户暂定GitHub为当前开发工作库；正式说明中的学校GitLab及GitLab CI要求保留，后续对接须保留历史和证据。当前没有据此新建CI或改变平台配置。
8. 输入与选择规则以08为细化依据，日志与证据以09为细化依据。新增文件中的预期表/模板不是实际运行结果，保护措施尚需代码和配置落实。
9. 公共接口以10为详细契约：使用QRService实例的generate_qr方法，编码先取得bytes，轨迹由本请求TraceCollector保留，图像由持有方管理生命周期；文件协调角色待认领，GitHub保护/权限尚未配置。

- 用户已要求暂缓四人的真实分工与能力匹配；A/B/C/D继续作为功能角色代号，姓名、8位学号和实际归属以后确认。

- 按已确认的PyQt5方向验证Python 3.13.9、Qt运行库与matplotlib画布；另核查lint工具及GitLab CI Runner。
- 核查官方时间的时区与实际演示时段；文档按原文记录学校时间，不直接当作北京时间。
- 按08文档的暂行规则规划自动选择：小版本优先、ECC按L/M/Q/H；若教师另有解释，更新规则版本、测试与证据，不默默切换。
- 当前按GitHub组织开发和分支；冻结公共接口，后续对接学校GitLab的正式仓库、个人分支和CI要求并保留历史。
- 在编码落地时实施09中的日志告知、忽略规则、证据索引和故障反馈；目前这些保护配置和真实证据仍未建立。
- 编码前按10的冻结清单确认公共调用与数据格式；公共字段、行为、依赖变更走PR并请受影响方复核，真实人员以后再填写。
