# 图示说明

四张SVG为关键总览，同名PNG可用于不支持SVG的阅读器。均为拟议设计，不是实现或测试证据。

`02_01_架构.mmd`：系统组件关系；`02_02_架构.mmd`：模块调用时序。

`03_01_流程.mmd`：生成主流程；`03_02_流程.mmd`：版本/ECC选择；`03_03_流程.mmd`：掩码评分；`03_04_流程.mmd`：步骤展示；`03_05_流程.mmd`：日志分析；`03_06_流程.mmd`：团队开发与交付。

详细Mermaid源同时嵌入上级02、03文档。支持Mermaid的阅读器可以渲染，普通浏览器可直接打开SVG。SVG/PNG为总体阅读视图，不与详细Mermaid逐节点一一对应；总体模块、角色和顺序必须一致。

更新方式：先修改Markdown图块，再同步对应.mmd；总体关系变化时一并修订SVG/PNG。不要只更新导出的图片。

文字与颜色双重标识角色，灰度下仍可阅读。SVG保留文本和可缩放结构，包含标题和文字替代说明；PNG为同一布局的静态备用。宽图建议横屏或放大，不将文字压缩到无法阅读。
