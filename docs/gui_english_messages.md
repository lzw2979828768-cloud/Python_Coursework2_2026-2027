# 桌面提示语言修复

2026-11-12，在 `feature/stage2-gui-environment` 保留原布局，仅修复桌面界面的提示语言。

- 空输入、不支持的字符、超容量及其他生成失败，依据原有错误码显示英文提示。
- 纯空白和日志失败警告使用英文；日志失败不重复显示，也不直接拼接内部诊断信息。
- PNG 保存失败对话框使用英文，提示检查目录、文件名和写入权限。
- 原始 QRResult、服务错误码、中文 CLI 和核心编码行为保持不变。

58 项前端相关测试全部通过。测试增加了英文提示、原始错误保留、警告去重和保存失败文案的断言；Qt 离屏控件交互检查通过。
